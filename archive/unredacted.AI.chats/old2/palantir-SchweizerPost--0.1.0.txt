Bedeutung von LQ (Lieferqualitätsgarantie)

LQ bedeutet, dass die Sendung mit einer besonderen Garantie für die Lieferqualität versendet wurde.
Diese Garantie umfasst in der Regel eine pünktliche Zustellung innerhalb einer festgelegten Frist (z. B. am nächsten Werktag bis 17:00 Uhr).
Falls die Sendung nicht fristgerecht zugestellt wird, kann der Absender unter bestimmten Bedingungen eine Rückerstattung der Versandkosten beantragen.
Wichtig:

Die Lieferqualitätsgarantie gilt nur für Inlandssendungen in der Schweiz.
Sie ist an bestimmte Bedingungen geknüpft, z. B. korrekte Adressangaben und rechtzeitige Aufgabe der Sendung.

import requests
import json
from datetime import datetime

# Post.ch Tracking API (hypothetisch – muss angepasst werden)
TRACKING_URL = "https://api.post.ch/tracking/{YOUR_TRACKING_NUMBER}"
HEADERS = {"User-Agent": "Mozilla/5.0"}

def log_tracking(tracking_number):
    response = requests.get(TRACKING_URL.format(tracking_number), headers=HEADERS)
    data = response.json()

    # Speichere Rohdaten mit Zeitstempel
    timestamp = datetime.now().isoformat()
    filename = f"post_tracking_{timestamp}.json"
    with open(filename, "w") as f:
        json.dump(data, f, indent=2)

    # Prüfe auf Anomalien
    if "error" in data and data["error"] == "unknown":
        print(f"⚠️  {timestamp}: UNBEKANNTER FEHLER in API-Antwort!")
    if "qrcode" not in data:
        print(f"⚠️  {timestamp}: QR-Code fehlt in API-Daten!")

# Alle 5 Minuten abfragen
while True:
    log_tracking("DEINE_SENDUNGSNUMMER")
